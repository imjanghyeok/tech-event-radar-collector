# Tech Event Radar Collector

한국 개발자 행사·스터디·동아리의 공개 목록을 하루 한 번 직접 수집합니다. GPT 예약 작업이나 모델 API를 사용하지 않습니다.

- 매일 한국 시간 09:17, GitHub Actions의 표준 Ubuntu 러너에서 실행합니다.
- Actions → Daily tech event collection → Run workflow로 수동 실행할 수 있습니다. 기본값은 당일 중복 실행을 건너뜁니다. `force`는 당일 재실행만 허용하며 동시 실행 방지는 유지합니다.
- 후보 대기열·재시도·다음 처리 시각·실행 잠금은 사이트의 외부 D1 DB에 보존합니다. 러너의 로컬 파일은 다음 실행에 필요하지 않습니다.
- 한 번에 원문 최대 80개를 검증합니다. 남은 후보는 다음 실행에서 이어 처리합니다. 동적 페이지는 전용 Chromium으로 읽고, robots/로그인/보안 확인을 우회하지 않습니다.
- 저장된 공개 결과와 소스별 성공·0건·접근 제한·실패는 [레이더](https://tech-event-radar-kr.qkdrhkgn123.chatgpt.site/radar)에서 확인합니다.
- 인증 키는 저장소의 Actions secret `RADAR_BATCH_KEY`에만 설정합니다. 이 저장소에는 개인 프로필, 로컬 DB, 수집 원문, 인증 키가 없습니다.
- 공개 저장소의 표준 GitHub 러너 실행 시간은 무료입니다. 유료 대형 러너, 별도 캐시·아티팩트 업로드를 사용하지 않습니다. 사이트 호스팅의 별도 이용 조건은 적용됩니다.
- 예약은 지연되거나 누락될 수 있습니다. 공개 저장소에서 60일간 저장소 활동이 없으면 GitHub가 예약을 중지할 수 있으므로, 사이트의 36시간 실행 지연 경고와 Actions 상태를 확인하세요. 매일 불필요한 커밋을 생성하지 않습니다.

`partial`은 배치가 정상 종료됐지만 일부 소스 또는 원문을 확인하지 못했다는 뜻입니다. `failed`는 배치 처리 실패이며 Actions도 실패로 종료합니다. 사이트에는 예약 활성 확인 시각과 실제 실행 결과가 별도로 표시됩니다.
